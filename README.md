# Clash Upgrade Widget (scaffold)

Android home-screen widget that shows countdowns for in-progress Clash of Clans
upgrades, read from the in-game **village data export** (JSON).

## Run
One command builds, starts the emulator (`coc_pixel`) if it isn't running, installs and opens the app:

```bash
./run.sh
```

Then in the app: **Load sample** (or **Paste from clipboard** after copying your village
data in-game) → **Add widget to home screen**.

Other commands:
- Unit tests: `./gradlew :app:testDebugUnitTest`
- APK only: `./gradlew :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`

Tooling (installed via Homebrew): Android command-line tools in
`/opt/homebrew/share/android-commandlinetools` (path is in `local.properties`), JDK 17.
The project also opens fine in Android Studio.

## Layout
| Path | What |
|---|---|
| `data/Models.kt` | Export JSON shape (`VillageExport`) + stored `Snapshot`/`Upgrade` |
| `data/ExportParser.kt` | Pure parser: keeps entries with `timer`, computes `finishAt = timestamp + timer` |
| `data/UpgradeRepository.kt` | Persists the snapshot in DataStore |
| `data/GameNames.kt` + `assets/names.json` | Data ID → name lookup |
| `ui/MainActivity.kt` | Import screen with live in-app countdowns |
| `widget/UpgradesWidget.kt` | Glance widget; soonest upgrade uses a live `Chronometer` |
| `widget/WidgetRefresh.kt` | 15-min WorkManager refresh + alarm at next finish time + boot re-arm |
